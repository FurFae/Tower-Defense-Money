# Чек-лист перед релизом (roadmap item 11)

## Код
- [ ] EditMode-тесты зелёные (Test Runner → EditMode): экономика, эффекты, таргетинг
- [ ] Нет ошибок компиляции в консоли, нет missing references в сценах
- [ ] Сейвы: старый сейв с версией < текущей загружается и мигрирует (проверить на тестовом профиле)

## Бой
- [ ] Построить каждую из 7 башен: выстрел, звук, отдача, улучшение +1/+2, продажа возвращает ~70%
- [ ] Приоритеты целей переключаются у башни, ядовитая башня меняет режим яда
- [ ] ×2 ускоряет бой, пауза работает в обоих режимах скорости
- [ ] Кнопка «волна сейчас» даёт +15 маны, предпросмотр состава совпадает с реальной волной
- [ ] Статус-иконки (яд/замедление/поджог) появляются и исчезают над врагами
- [ ] Круг радиуса при выборе башни и наведении в меню строительства

## Враги и карты
- [ ] Уровень 1: бронежуки, стремительные, целитель
- [ ] Уровень 2: летающие (пушка/огнемёт/лед не бьют их), делящиеся, маршрут отзеркален, часть слотов закрыта
- [ ] Уровень 3: магический жук снимает эффекты, босс в финальной волне, маршрут смещён
- [ ] Босс: отдельная награда, урон замку 5

## Прогрессия
- [ ] Челленджи: «без ремонта» отключает ремонт, «только редкие» закрывает дешёвые башни, награды ×1.5/×2
- [ ] Победа/поражение: звуки, награды, следующий уровень открывается

## Платформы
- [ ] WebGL: сборка из CI, сейвы в PlayerPrefs/облако, звуки идут после первого взаимодействия
- [ ] Сенсорный ввод: тап по слоту открывает меню, тап по башне — панель
